# Connexion au serveur IRC

## Pre-requis

Le serveur doit etre demarre sur la machine hote (docker compose up -d).
Le proxy Tor est accessible sur 127.0.0.1:9050.

## Installation

1. Telecharge et installe HexChat : https://hexchat.github.io
2. Copie le dossier HexChat\ dans %APPDATA%\
   (Chemin complet : C:\Users\TON_NOM\AppData\Roaming\HexChat\)
3. Lance HexChat
4. Le reseau "MonServeurIRC" apparait deja configure
5. Connecte-toi
